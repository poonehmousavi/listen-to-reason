Listen-to-Reason: Hear with Experts, Think with LLM

Frozen expert audio encoders and small trained heads place every 3-second chunk of a clip in an explicit tree of named audio nodes. A frozen text-only LLM answers from those nodes and a transcript. It never hears the audio, and every answer can be traced to the nodes it read.
